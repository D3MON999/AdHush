Add AdHush Assistant to your browser

Keep this tab open and follow the steps. It takes about 20 seconds.

  1. Open the extensions page
    Click the address bar, paste with Ctrl+V and press Enter. The address is already copied.
    chrome://extensions
  2. Turn on Developer mode
    The switch is at the top right of the extensions page.
  3. Click Load unpacked
    Copy the folder path below, then in the window that opens paste it with Ctrl+V and click Select Folder.
    …
  4. Pin it
    Click the puzzle-piece icon in the toolbar and pin AdHush Assistant. You can close this tab now.

Why the manual steps? Browsers don't let programs add extensions by themselves, because that's how adware sneaks in.
